# 复现包审计清单

## 入口

- [ ] 是否有 README？
- [ ] README 是否说明数据来源、运行顺序和依赖？
- [ ] 主脚本是什么？

## 数据流

- [ ] 原始数据位于何处？
- [ ] 哪些脚本生成中间数据和分析数据？
- [ ] 是否存在手工修改或缺失的数据步骤？

## 输出映射

- [ ] 每张表对应哪个脚本？
- [ ] 每幅图对应哪个脚本？
- [ ] 论文中的主结果能否找到生成路径？

## 环境与日志

- [ ] 软件版本和依赖是否清楚？
- [ ] 是否需要受限数据、账号或 API？
- [ ] 报错、缺失文件和结果差异是否已记录？

## 人工判断

- [ ] 哪些变量定义无法从代码确认？
- [ ] 哪些识别假设需要回到论文和制度背景判断？
- [ ] 哪些结果不能仅凭代码运行认定为复现成功？
