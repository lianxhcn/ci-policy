## 资料与数据

- `data/raw/` 中的原始数据只读，不得覆盖或手工修改。
- 优先使用研究者提供的论文、数据源、API 和政策文件；未列入的网页或数据源需先说明并确认。
- 所有中间数据和分析数据由 `scripts/` 中的代码生成。
- 发现缺失、异常、口径差异或合并失败时，写入 `logs/data_issues.md`，不要自行删除观测。

## 代码与输出

- 新代码保存到 `scripts/`，不要只在对话窗口中给出代码。
- 每张表和每幅图必须能追溯到脚本、输入数据和运行日期。
- 输出保存到 `output/tables/` 或 `output/figures/`；不要覆盖旧结果。
- 记录 Stata、Python、R 和关键依赖版本；涉及随机过程时记录随机种子。

## 研究判断与确认

- 不擅自改变样本边界、核心变量、固定效应、聚类方式或识别策略。
- 不确定的政策事实、变量定义、文献链接和结果解释单列为待确认问题。
- 覆盖文件、删除文件、安装软件、调用外部 API 或提交 Git commit 前，先请求确认。
- 每完成一个阶段，汇总修改文件、主要结果和待确认问题，等待研究者反馈。
