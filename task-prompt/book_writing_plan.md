# ci-policy 写作计划

## 1. 书名与课程主题

书名暂定：

> 因果推断：政策评估中的识别思维与实证设计

课程时间：

```text
2026.7.14
上午 3 小时
下午 3 小时
```

听课对象：

```text
经管学院高年级硕士生、博士生，以及对政策评估实证研究有兴趣的青年教师
```

课程形式：

```text
不使用传统幻灯片，直接使用在线讲义网站授课。
讲义由 Quarto + GitHub Pages 发布。
配套 Stata 和 Python Notebook，以 Stata 为主。
```

## 2. 核心定位

这不是一门单纯的方法课，也不是金融计量或高级计量经济学课。

本课程要解决的问题是：

> 当我们准备评价一项政策的经济后果时，如何从政策背景出发，理解数据如何形成，识别哪些偏误可能存在，再选择合适的研究设计和估计方法。

因此，课程核心不是罗列方法，而是训练学生形成政策评估研究设计的完整工作流。

## 3. 总体逻辑

全书主线为：

```text
政策目标 → 政策实施机制 → 数据形成机制 → 识别威胁 → 研究设计 → 估计方法 → 结果解释
```

这条主线要贯穿所有章节。

具体解释如下：

- 政策目标决定结果变量；
- 政策实施机制决定处理变量、对照组和政策时点；
- 数据形成机制决定样本边界、样本选择和可观测性；
- 识别威胁决定需要处理哪些偏误；
- 研究设计决定反事实如何构造；
- 估计方法只是服务于识别设计的工具；
- 结果解释必须回到政策目标和估计量含义。

## 4. 核心案例安排

本讲义采用「一个主例 + 一个副例 + 一个开放讨论」的结构。

### 4.1 主例：Lane (2025), QJE

Nathan Lane (2025) 关于韩国重化工业政策的论文作为主线案例。

用途：

- 讲政策背景如何进入数据；
- 讲政策对象和对照组如何界定；
- 讲产业政策如何产生直接效应和间接效应；
- 讲 DID、DDD、IPW、DR DID 等方法为何组合使用；
- 讲如何将完整复现包拆成多个学习任务。

### 4.2 副例：Abadie et al. (2010), JASA

加州禁烟政策和合成控制法作为副例。

用途：

- 讲少数处理对象时反事实如何构造；
- 讲 donor pool、政策前路径拟合和安慰剂检验；
- 讲为什么一个州、一个地区、一个行业也可以做政策评估，但识别设计必须更谨慎。

### 4.3 开放讨论：政府引导基金与产业链长鞭效应

政府引导基金案例作为开场或结尾讨论。

用途：

- 训练学生从政策目标推导结果变量；
- 比较企业层面结果变量和产业链层面结果变量；
- 说明政策评估中的研究问题设定本身就是识别设计的一部分。

## 5. 章节结构

### 第 1 章 政策评估从政策目标开始

目标：让学生明白政策评价不是先找模型，而是先理解政策目标。

重点：

- 政策为什么发生；
- 谁实施政策；
- 政策对象是谁；
- 政策希望改变什么；
- 结果变量如何从政策目标中推导；
- 政府引导基金案例。

### 第 2 章 政策如何进入数据：处理组、对照组与政策时点

目标：把政策背景翻译成实证变量。

重点：

- $Y$、$D$、$Post$ 的含义；
- 处理组如何定义；
- 对照组如何选择；
- 政策时点如何界定；
- 政策是否分批实施；
- 批次之间是否可比；
- 地理相邻、产业相邻和网络外溢。

### 第 3 章 谁被我们看见了：样本选择、自选择与 Heckman 思维

目标：让学生意识到自己手里的数据往往是选择后的数据。

重点：

- 工资只在就业者中可观测；
- 贷款利率只在获得贷款企业中可观测；
- 政府补贴、专利、上市公司、存活企业样本中的选择机制；
- 选择方程和结果方程；
- 排他性约束；
- Heckman 两步法的直观含义；
- 平衡性检验不能替代选择机制讨论。

### 第 4 章 遗漏变量如何进入模型：控制变量、固定效应、HDFE 与 IntFE

目标：把固定效应讲成遗漏变量控制策略，而不是面板回归标配。

重点：

- 控制变量为何服务于识别；
- 固定效应控制什么；
- 固定效应不能控制什么；
- HDFE 如何改变比较范围；
- IntFE 如何处理共同冲击的异质暴露；
- 固定效应的代价：识别变异减少。

### 第 5 章 如何构造反事实：DID、DDD、事件研究与合成控制

目标：把 DID、DDD 和 SCM 都讲成反事实构造方法。

重点：

- DID 的反事实逻辑；
- 平行趋势是假设，不是图形装饰；
- 事件研究如何展示政策前趋势和动态效应；
- DDD 为什么需要第三层比较；
- 合成控制法如何处理少数处理对象；
- donor pool、政策前拟合和安慰剂检验。

### 第 6 章 控制关系不再线性时：FWL、DDML 与设定偏误

目标：讲清楚 DDML 的适用边界。

重点：

- FWL 定理的直观含义；
- 控制变量的本质是 partial out；
- 线性控制与非线性控制；
- DDML 解决的是高维和非线性控制下的设定偏误；
- DDML 不能自动解决不可观测混杂、自选择、排他性约束不成立等问题。

### 第 7 章 从论文阅读到复现：AI 和 Agent 如何帮助继续学习

目标：把课堂内容转化为课后学习和复现工作流。

重点：

- AI 不能替代识别判断；
- AI 可以帮助拆政策背景、变量定义、识别策略和复现包结构；
- Codex / Claude Code 适合在本地运行复现包、定位主脚本、整理结果；
- 如何把一篇论文拆成 5 个任务；
- 如何从复现迁移到自己的研究问题。

### 第 8 章 扩展阅读：书籍、连享会资料与在线课程

目标：给学生一个课后学习路线。

重点：

- 入门教材；
- online book；
- 连享会推文；
- 方法专题索引；
- 可运行代码资源；
- 推荐学习顺序。

### 附录 A 可复现经典论文清单

目标：提供 6–8 篇适合课后练习的经典论文。

每篇包括：

- 期刊；
- 方法；
- 识别策略；
- 复现材料；
- 适合练习的任务；
- 200–300 字介绍。

## 7. 讲义详略原则

课堂主讲章节每章控制在 4000–6000 字左右。

不要把方法细节全部写入正文。详细方法、代码实现和经典论文放入：

```text
notebooks/
resources/
cases/
exercises/
附录
```

课堂正文应优先回答：

- 这个政策评估问题中的真实困难是什么；
- 数据为什么不能直接回答因果问题；
- 识别威胁在哪里；
- 这个方法回应了哪一类识别威胁；
- 这个方法还有什么边界。

## 8. Notebook 原则

涉及代码的部分使用 Notebook 或配套脚本。

Notebook 不是完整方法教程，而是最小可运行例子，用来展示：

- 选择机制如何造成偏误；
- 固定效应如何改变比较范围；
- DID 估计量如何依赖平行趋势；
- FWL 如何 partial out；
- DDML 如何处理非线性控制关系。

每个 Notebook 必须说明：

- 数据来源；
- 代码做什么；
- 结果看哪里；
- 结果如何解释；
- 这个示例有哪些局限。
