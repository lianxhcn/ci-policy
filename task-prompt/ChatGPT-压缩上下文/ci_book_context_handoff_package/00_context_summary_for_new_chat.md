# 新对话上下文摘要

## 项目名称

《因果推断：政策评估中的识别思维与实证设计》

## 全书定位

本书面向经管、管理、金融、社会科学方向的研究生和青年研究者。它不是命令手册，也不是只列参考资料的阅读指南，而是一套围绕政策评估展开的实证研究设计讲义。

全书主线是：

```text
政策背景 → 政策实施机制 → 数据形成机制 → 样本进入机制 → 比较对象 → 反事实构造 → DID 方法选择 → 高维控制 / DDML → AI Agent 工作流
```

本书的目标是让读者理解：实证研究不是从回归命令开始，而是从政策制度、处理对象、数据形成、样本进入和反事实构造开始。

## 全书章节安排

### 第一章：从政策背景到研究设计

强调政策评估从政策制度和实施机制开始，而不是从回归模型开始。研究者要先弄清楚政策目标、政策对象、实施时间、地区范围、执行强度和潜在受影响主体。

### 第二章：从政策到数据

以 Lane (2025) 韩国 HCI 产业政策为主案例，讲政策文本、处理组、政策时点、产业分类、结果变量和数据匹配。重点是说明变量不是凭空出现的，处理变量、结果变量和机制变量都应从政策实施机制中找到来源。

### 第三章：谁进入样本，谁被我们观察到

讲样本选择、样本进入机制、Heckman 模型和 Mroz 数据。重点是说明很多偏误不是来自回归公式，而是来自样本进入规则与潜在结果之间的系统性关联。

### 第四章：看见之后，如何比较：固定效应在控制什么

讲控制变量、好控制 / 坏控制、固定效应、TWFE、HDFE、交互固定效应，以及固定效应如何改变比较对象。核心判断是：固定效应不是回归表底部的装饰，而是在声明「拿谁和谁比」。

### 第五章：如果没有政策，会发生什么：反事实构造的基本思路

由另一个 AI 正在撰写。核心逻辑是从 Abadie et al. (2010) 加州禁烟图出发，依次讲 ITSA / 时间趋势外推、DID、RDD 的局部反事实、SCM、RCM / GSC、SDID。重点是反事实构造，不讲现代 DID 估计量细节。

### 第六章：双重差分法怎么选：从 TWFE 到现代 DID 估计量

已经生成规划文档和 A6 附录骨架。正文结构定为 9 节：

```text
为什么 DID 方法突然变多了
从 2×2 DID 看清楚「两次差分」
交错处理：TWFE 到底在比较谁

DDD：什么时候需要第三重差异

```

第六章新增吸收 `A5-03-OLS-FWL定理-DID.md` 中「FWL 应用 4：倍分法 (DID)」的核心内容，用四个均值和一个交互项解释 2×2 DID：

$$
y_{it}
=
\alpha
+\theta_1 Treat_i
+\theta_2 Post_t
+\gamma (Treat_i\times Post_t)
+\varepsilon_{it}
$$

四个均值为：

$$
C_0=E(y_{it}\mid Treat=0,Post=0)
$$

$$
Y_0=E(y_{it}\mid Treat=1,Post=0)
$$

$$
C_1=E(y_{it}\mid Treat=0,Post=1)
$$

$$
Y_1=E(y_{it}\mid Treat=1,Post=1)
$$

因此：

$$
\gamma=(Y_1-C_1)-(Y_0-C_0)=(Y_1-Y_0)-(C_1-C_0)
$$

这说明 DID 的核心不是比较政策后处理组和控制组，也不是只比较处理组政策前后，而是用控制组的同期变化扣除共同时间趋势。Card and Krueger (1994) 最低工资案例可作为 2×2 DID 的经典例子。
