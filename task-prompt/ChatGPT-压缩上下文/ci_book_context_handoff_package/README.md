# 因果推断讲义：新对话交接包

本包用于把当前长对话中的关键信息转移到新对话框中，便于继续讨论第六章、第七章和第八章。

## 文件说明

```text
00_context_summary_for_new_chat.md
```

当前项目上下文摘要，包括全书定位、八章安排、前六章状态和后续建议。

```text
01_book_writing_style_and_design_principles.md
```

全书写作风格与设计原则。建议在新对话中优先提供给 AI，让它理解这本讲义不是资料索引，也不是命令手册，而是「图形直觉 + 公式逻辑 + 附录代码 + 可复现文献」的完整学习链路。

```text
02_chapter6_did_materials_inventory.md
```

第六章 DID 方法选择的材料汇总，尤其包括 FWL-DID 讲义、2×2 DID 四格均值、Card and Krueger 案例、A6 附录和需要制作的图形。

```text
03_prompt_for_new_chat.md
```

可直接复制到新对话框的开场提示词。

## 使用建议

1. 新开对话框；
2. 上传或粘贴 `00_context_summary_for_new_chat.md`；
3. 上传或粘贴 `01_book_writing_style_and_design_principles.md`；
4. 若继续第六章，上传或粘贴 `02_chapter6_did_materials_inventory.md`；
5. 使用 `03_prompt_for_new_chat.md` 作为开场提示词。
