## 4. 主案例：妇女工资与劳动参与

请把「妇女工资」作为第 3 章的主案例，并完整回答以下问题。

### 4.1 Full sample 是什么？

总体样本不是「有工资的妇女」，而是：

```text
所有处于劳动年龄、理论上可能参与劳动市场的妇女。
```

其中包括：

- 已经工作并有工资的妇女；
- 没有工作的妇女；
- 暂时退出劳动力市场的妇女；
- 因家庭照护、丈夫收入、孩子数量、地区就业机会等原因没有工作的妇女。

### 4.2 Observed sample 是什么？

结果方程中可用的样本是：

```text
已经工作并能观察到工资的妇女。
```

也就是说，工资 `W_i` 只在 `S_i=1` 时可观测。

这里的选择变量可以定义为：

```text
S_i = 1：妇女参与劳动市场且有可观测工资
S_i = 0：妇女没有参与劳动市场，因此工资不可观测
```

### 4.3 为什么会有选择偏误？

没有工作的妇女不是随机消失的。劳动参与决策可能与潜在工资能力相关。

例如：

- 教育程度较高的妇女更可能工作，也可能获得更高工资；
- 工作经验较多的妇女更可能继续工作，也可能获得更高工资；
- 家庭经济压力较大的妇女更可能工作；
- 丈夫收入较高或家庭收入较高的妇女可能更少参与劳动市场；
- 有年幼子女的妇女可能更少参与劳动市场。

如果这些因素中有一部分不可观测，且同时影响劳动参与和潜在工资，那么只在工作妇女样本中估计工资方程就会产生选择偏误。

### 4.4 选择方程怎么设定？

选择方程回答的是：

```text
哪些因素影响一个妇女是否出来工作？
```

示例：

```markdown
$$
S_i^* = Z_i'\gamma + v_i,\quad S_i = 1(S_i^*>0)
$$ {#eq:cipolicy-selection-wage-participation}
```

选择方程可以包括：

- 年龄；
- 教育程度；
- 工作经验；
- 婚姻状态；
- 子女数量；
- 年幼子女数量；
- 丈夫收入；
- 家庭非劳动收入；
- 家庭资产或其他收入；
- 地区就业机会；
- 地区托育资源。

### 4.5 结果方程怎么设定？

结果方程回答的是：

```text
对于已经工作的妇女，哪些因素影响她的工资水平？
```

示例：

```markdown
$$
W_i = X_i'\beta + u_i,\quad W_i \text{ is observed only if } S_i=1
$$ {#eq:cipolicy-selection-wage-outcome}
```

结果方程通常包括：

- 教育程度；
- 工作经验；
- 年龄；
- 行业；
- 职业；
- 地区；
- 工时；
- 企业类型。

### 4.6 排他性变量如何找？

本案例必须重点解释排他性变量。

排他性变量应满足：

```text
影响是否工作，但不直接影响已经工作后的工资水平。
```

在妇女工资案例中，可以讨论：

1. **丈夫收入**  
   丈夫收入越高，家庭对妇女工资收入的依赖越低，妇女劳动参与倾向可能下降。但在控制教育、经验、行业、职业和地区后，雇主通常不会因为一个妇女丈夫收入高，就给她更高或更低工资。

2. **家庭非劳动收入**  
   家庭有更多财产性收入、转移收入或其他非劳动收入时，妇女参与劳动市场的经济压力下降。但这些收入通常不直接进入雇主的工资定价。

3. **年幼子女数量或托育可得性**  
   照护责任会明显影响劳动参与，托育资源会降低参与劳动的家庭成本。但若已经控制工作岗位、教育、经验和地区，它们未必直接决定单位小时工资。

注意：这些变量是否真正满足排他性约束，需要结合制度背景和数据结构论证，不能机械套用。

### 4.7 为什么这些变量不适合进入结果方程？

请明确解释：

- 丈夫收入和家庭非劳动收入影响的是「是否出来工作」；
- 雇主决定工资时，主要看劳动者的人力资本、岗位、行业、地区和企业特征；
- 如果将丈夫收入直接放入工资方程，需要解释雇主为什么会基于丈夫收入定价；
- 如果无法说清这个机制，就不应把它当成工资方程的直接解释变量。

但也要提醒：

- 如果丈夫收入通过居住区、社会网络、职业选择等渠道影响工资，那么排他性约束可能被破坏；
- 如果托育资源影响妇女选择的岗位类型或工时，也可能间接影响工资；
- 因此，排他性变量不是凭直觉选出来的，而是要写出制度机制和反驳可能的违反路径。

## 5. 辅助案例 1：贷款或绿色信贷获得

用较短篇幅说明如何迁移主案例逻辑。

### 5.1 Full sample

所有理论上可能申请贷款或绿色信贷的企业。

### 5.2 Observed sample

能够观察到贷款利率、贷款额度或贷款期限的企业，通常是已经获得贷款的企业。

### 5.3 Selection mechanism

企业是否获得贷款可能取决于：

- 信用记录；
- 抵押物；
- 银企关系；
- 所在地区金融供给；
- 银行网点密度；
- 政策性金融覆盖；
- 企业规模和盈利能力。

### 5.4 可能的排他性变量

可以讨论但不得武断确认：

- 地区银行网点密度；
- 历史银行分支机构布局；
- 政策性金融机构覆盖；
- 到最近银行网点的距离；
- 地方绿色金融政策试点资格。

必须说明：

这些变量是否只影响「获得贷款的机会」，而不直接影响「贷款后的企业绩效」或「贷款利率」，需要仔细论证。

## 6. 辅助案例 2：政府补贴申请或获得

用较短篇幅说明政策评估中的选择后样本。

### 6.1 Full sample

所有理论上有资格申请政策补贴的企业。

### 6.2 Observed sample

已经申请、披露或获得补贴的企业。

### 6.3 Selection mechanism

补贴获得可能取决于：

- 企业是否知道政策；
- 是否有能力准备申请材料；
- 是否符合申报门槛；
- 是否位于政策重点地区；
- 是否属于政策重点行业；
- 是否与政府部门有更多接触机会。

### 6.4 可能的排他性变量

可以讨论但不得武断确认：

- 政策宣传覆盖；
- 到政策服务窗口的距离；
- 地方申报服务平台上线时间；
- 历史申报惯性；
- 同地区同行业申报氛围。

必须提醒：

如果这些变量同时影响企业绩效、创新能力或资源获取能力，就不适合作为排他性变量。

## 7. 开放讨论：政府引导基金案例

用户已经明确指出：

> 政府引导基金案例中，到底哪些变量适合进入 selection function、且不进入 outcome equation，目前并没有想清楚。

请不要假装已经解决。

本章应把政府引导基金写成开放讨论，而不是给出虚假的排他性变量。

可以写：

```text
政府引导基金案例更难，因为基金选择企业往往同时考虑行业前景、企业潜力、产业链位置、地方政府产业目标等因素。这些因素不仅影响企业是否被投，也可能直接影响后续融资、创新或供应链稳定。因此，很多看似适合进入选择方程的变量，都可能同时影响结果方程。
```

可以提出候选方向，但必须明确它们只是候选，不是已经成立的识别变量：

- 基金设立时点与企业成立时点的错位；
- 地方政府引导基金预算约束；
- 基金管理机构覆盖范围；
- 企业是否处于基金重点招商园区；
- 政策宣传或申报渠道可达性；
- 基金投资委员会或管理机构的外部约束。

但必须逐一提醒：这些变量是否排他，需要进一步论证。

本章对政府引导基金的结论应是：

```text
如果找不到能够说服读者的排他性变量，不要为了使用 Heckman 而硬造变量。此时更好的做法是把选择机制讲清楚，报告样本进入规则，做敏感性分析，并考虑替代研究设计。
```
