## 1. 本轮核心调整

本讲义虽然会在某一次线下课程中使用，但后续还会迁移到其他课程和暑期班中。因此，正式讲义不要写成某一天、某个学校、某个具体班级的专属课件。

正式讲义应定位为一套可复用的在线讲义：

> 因果推断：政策评估中的识别思维与实证设计

请注意：

- 不要在 `index.qmd`、`syllabus.qmd` 或各章中写入具体授课日期；
- 不要写具体授课地点；
- 不要写特定学校名称；
- 不要把听课对象写成某一次课程的专属对象；
- 可以写成「本讲义适合希望理解政策评估研究设计的经管类研究生和实证研究者」；
- 课程安排可以写成「建议 6 小时讲授路线」，而不是「某年某月某日课程安排」。

## 2. 项目定位

本项目是一套在线讲义，不是传统 PPT，也不是方法百科。

讲义主线必须围绕：

```text
政策目标 → 政策实施机制 → 数据形成机制 → 识别威胁 → 研究设计 → 估计方法 → 结果解释
```

所有方法都必须从政策评估中的具体问题引出。不要按 DID、RDD、IV、Heckman、SCM、HDFE、DDML 等方法孤立铺开。

Lane (2025) 仍作为全书主线案例，贯穿第 1、2、5、7 章。
