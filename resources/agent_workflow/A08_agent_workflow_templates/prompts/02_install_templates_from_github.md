# 从 GitHub 下载模板：提示词

```text
请从公开 GitHub 仓库下载 A8 Agent 工作流模板包，并安装到我指定的新项目文件夹。

仓库地址：https://github.com/lianxhcn/ci-policy
模板目录：resources/agent_workflow/A08_agent_workflow_templates
目标项目目录：{填写本地项目目录}
研究主题：{填写研究主题}

执行要求：
1. 先检查目标目录是否为空；如果已有文件，只列出冲突，不覆盖；
2. 只下载模板包，不下载 `refers/`、`working/` 或其他无关目录；
3. 复制后根据研究主题生成目录建议和待填写字段清单；
4. 不下载数据、不运行代码、不安装软件；
5. 最后报告下载了哪些文件、哪些模板需要研究者填写。
```
